Conectar TikTok

Desde aquí das permiso (solo de lectura) para que tu web muestre tu foto de perfil y tus vídeos de @zoqueteilustrado. No hace falta tocar nada más en esta página después de conectar.

1 · Conectar

Pega la Client key de tu app de TikTok (está en developers.tiktok.com, en tu app). No es secreta: se guarda solo en este navegador.

Dirección de vuelta que debes registrar en TikTok (Login Kit → Redirect URI), exactamente así:

2 · Pasa el código a GitHub

TikTok ha dado permiso. Este es tu código de un solo uso; caduca pronto, así que haz el siguiente paso ahora.

Abrir el proceso en GitHub
  1. En GitHub, pulsa Run workflow.
  2. Pega el código en el campo Código de TikTok y pulsa el botón verde Run workflow.
  3. Espera a que salga el tic verde (1–2 minutos) y mira la sección Redes de tu web.

Empezar de nuevo

Clave para cifrar (TOKEN_KEY)

Solo hace falta una vez. Genera una clave aleatoria aquí mismo (no sale de tu iPad), cópiala y guárdala en GitHub como el secreto TOKEN_KEY. Sirve para cifrar el acceso de TikTok dentro de tu repositorio.

Si un día la cambias en GitHub, tendrás que volver a conectar TikTok.
